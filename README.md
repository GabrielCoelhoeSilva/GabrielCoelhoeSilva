## 🚀 Projeto em Destaque

### 🎬 [Movie Booking API](https://github.com/GabrielCoelhoeSilva/movie-booking-api)
API REST completa para reserva de ingressos de cinema, construída para praticar arquitetura backend de verdade — do desenho do banco de dados à autenticação de usuários.

**O que o projeto entrega:**
- 🔐 Autenticação e autorização com **Spring Security + JWT** (roles `CUSTOMER` / `ADMIN`)
- 🏗️ Arquitetura em camadas: `Controller → Service → Repository`, com **DTOs** e **Mappers** separando a entidade da API
- 📅 Regras de negócio reais: geração automática de assentos por sessão, validação de conflito de horário, **expiração automática de reservas via scheduler**
- ⚠️ Tratamento global de exceções (`GlobalExceptionHandler`)
- 🗄️ Persistência com **Spring Data JPA + PostgreSQL**
- 📖 Documentação interativa com **Swagger/OpenAPI**

**Stack:** `Java 21` `Spring Boot 3.3` `Spring Security` `Spring Data JPA` `PostgreSQL` `JWT` `Swagger` `Maven`

➡️ [Ver repositório completo](https://github.com/GabrielCoelhoeSilva/movie-booking-api)
