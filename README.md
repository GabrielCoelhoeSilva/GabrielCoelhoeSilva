<p>
Sou Gabriel Coelho, estudante de Análise e Desenvolvimento de Sistemas
com foco em desenvolvimento backend. Minha meta é me tornar Engenheiro
de Software especializado em Java, construindo sistemas robustos,
escaláveis e orientados a boas práticas de engenharia.
</p>

<p>
Desenvolvo APIs REST completas com Spring Boot, aplicando autenticação
JWT, Spring Security, arquitetura em camadas com Spring Data JPA,
DTOs e tratamento global de exceções. Documento contratos de API com
Swagger/OpenAPI e monitoro aplicações com Spring Boot Actuator,
Prometheus e Grafana. Escrevo testes unitários com JUnit e Mockito
e testes de integração com MockMvc, garantindo cobertura real das
regras de negócio. Trabalho com Docker para conteinerização e
Git/GitHub com commits convencionais. Atualmente estudo arquitetura
de microsserviços com Spring Boot e RabbitMQ, evoluindo para padrões
de sistemas distribuídos e aprofundando conhecimentos em cloud com
AWS — EC2, RDS, S3 e IAM.
</p>
